# 2026-07-28 — Topology

Topics: `topology` (1), `bff-alternative` (2). Both settled.

## Covered

- Laid out the questions the `topology` topic has to answer, and the three candidate
  architectures (app-shell runtime composition, independent navigational composition,
  Microsoft's BFF / token handler) plus a fourth "independent plus ported pack pieces".
- User chose navigational composition, child-owned `index.html`, and introduced a
  requirement not present in either source: shared runtime config served from
  `/portal-runtime.json`.
- Settled the four dependent questions: runtime-config scoping, BFF, launch entitlement,
  cross-tab logout.
- Wrote `curated/topology.md`.

## Decided

- `0002` — navigational composition. Three documents, three MSAL instances, `/child0/*`
  serves child0's HTML, state shared only through the same-origin MSAL cache.
- `0003` — MSAL stays in the browser; BFF rejected. 24h refresh-token wall and shared XSS
  blast radius accepted explicitly.
- `0004` — one `/portal-runtime.json`, keyed by application id, each app reads only its
  own key, `no-store`, no secrets.
- `0005` — port the pack's portal launch-entitlement check (`canLaunch` + guard + denial
  route).
- `0006` — port the pack's payload-free `BroadcastChannel` logout signal.
